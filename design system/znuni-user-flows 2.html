TAB ARCHITECTURE
Three tabs, two flows
Everything that exists today, restructured around user intent instead of feature type.

📋 Today

The planner. One home for all planning, any date, any city.

Date picker — Today / Tomorrow / Sat / Sun / Pick date (14-day range)
City context — "in Zürich" default, changes to destination city from sunshine/snow flow
Plan/News toggle — Plan sub-view (agenda) + News sub-view (local feed)
Calendar sync — EventKit anchors auto-imported
Agenda composer — GapAnalysis → FreshnessScorer → Claude API → timeline
Execution mode — "Let's go" → progress dots, check-in, timeline shift
Weather — per-day forecast in header, drives indoor/outdoor pool

🧭 Discover

Inspiration hub. All reasons to plan, all things to explore.

Smart nudge — contextual: sunshine escape, upcoming event, holiday reminder
☀️ Where's the sun — sunshine ranking → city detail → "Plan a day here →"
❄️ Where's the snow — snow/ski conditions → resort detail → "Plan a ski day →"
📅 What's happening — events calendar → "Plan around this →"
Explore nearby — Activities, Museums, Parks, Restaurants by category
Every card has "Plan this →" — universal entry point into Today tab

What's eliminated

Weekend tab — planner moves to Today (date picker), sunshine/snow moves to Discover
Activities tab — merges into Discover → Explore nearby
Explore tab — merges into Discover (events + map + categories)
Duplicate planning UIs — one planner, not two

What's new

Date picker — extends planner beyond today/tomorrow to any date in 14 days
City context parameter — planner works for any city with venue data
Smart nudge — proactive suggestions based on weather patterns + upcoming events
"Plan this →" universal CTA — every discovery card links to planner

Flow routing

How every entry point connects to the planner:

Blank slate → Today tab (no anchors, no city override) → full auto-compose
Calendar event → Today tab (anchor pre-loaded) → gap fill
City event → Discover → anchor form → Today tab (date + anchor) → gap fill
Sunshine city → Discover → city detail → Today tab (city override + date) → compose
Snow resort → Discover → resort detail → Today tab (city override + date) → compose
Activity card → Discover → "Plan around this" → Today tab (venue as anchor) → gap fill
Push notification → deep link → Today tab (date + context pre-loaded)
