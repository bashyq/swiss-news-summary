How does the trip planner fit into the app?

Three ways to trigger "plan a day somewhere else" — consider how each feels in the existing UI

A

Smart Calendar Detection

App scans your calendar, spots events outside your home city, and surfaces a nudge card on the Plan tab:

📍 Away from home
Eye doctor in Meggen · Thursday
You're free before 10:00 and after 11:30. Want to plan the rest of the day?
Plan my day in Meggen
Dismiss

Feels magical — zero-effort discovery. But relies on calendar having location data, and could feel invasive if overdone.

B

Manual "Somewhere Else" Button

Add a button to the Plan tab hero banner (next to the city picker) that opens a destination search sheet:

Monday, March 23
Plan your Monday
Zürich ▾
🧳 Trip

Always available, user-initiated. Simple to implement — opens a search sheet where you type a destination and optionally add an anchor. No magic, no calendar scanning.

C

Both: Smart Detection + Manual Trigger

Calendar detection surfaces the nudge when it spots an away-from-home event. The manual "Trip" button is always there as a fallback for scenarios without calendar events (Grindelwald invite, spontaneous day out).

Calendar event detected: → nudge card appears automatically
No calendar event: → user taps "Trip" button → search sheet
Sunshine/Snow CTA: → goes straight to plan with destination pre-filled

Covers all three scenarios naturally. Calendar detection handles the Meggen/flat-viewing cases. Manual handles the Grindelwald invite. Sunshine/Snow handles the weather-chasing case. More to build, but each entry point is simple.
